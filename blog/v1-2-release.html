PDflow v1.2: A Faster,
Cleaner, Smarter UpdateNEW

A new template library, a 50% faster PDF export engine, a fully redesigned home UI, and a more reliable OCR engine. Everything stays local, free, and unlimited.

Release notes · v1.2.0 · June 23 2026 · 5 min read

01New Template Library

We rebuilt the template system from scratch. The new library ships with 6+ professionally designed templates for invoices, contracts, reports, announcements, and product specs — all built with the unified PDflow layout engine. Each template supports live preview, brand colors, and JSON-based customization, so you can tune every detail without rewriting from zero.

0250% Faster PDF Export

The export pipeline was rewritten around PyMuPDF's vector primitives. Large documents that used to take 6 seconds now export in under 3 — a 50% speedup on real-world reports with embedded images, tables, and CJK fonts. Memory usage during export was reduced by 30% as well, so longer documents stay responsive on modest hardware.

03Refreshed Home UI

The desktop homepage, the toolbox launcher, and the settings panel got a full visual pass. New typography scale, refined card spacing, and a redesigned navigation drawer make the app feel more cohesive. The theme system is unified through a single ThemeManager — no more drift between windows.

04Polished OCR Engine

RapidOCR now loads with a smarter preprocessing pass for deskew, denoise, and contrast normalization. Scanned invoices and receipts see 8–15% accuracy gains on small or low-DPI text. Multi-language CJK support is now on by default, with no extra model downloads.

05Bug Fixes & Stability

PDF merge now correctly preserves page rotation flags. Watermark preview no longer flickers on resize. Compress handles mixed-orientation pages without crashing. The template editor's undo history is now bounded to 100 steps, preventing runaway memory on long sessions.

06Upgrade & Feedback

v1.2 is a free, in-place upgrade — just install over v1.1. Settings, drafts, and your library are preserved. If you hit anything odd, please open an issue on GitHub or email us. v1.3 will focus on a visual layout canvas with snap guides and zoom controls.
