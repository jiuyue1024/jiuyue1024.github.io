What the current route proves on this file

Each priced line must satisfy Quantity × Unit Price = Amount, and the line amounts must add up to the document total. On this sanitized quotation, all 19 line items reconcile and the total is $71,816.00, matching the PDF.

If that arithmetic proof does not hold, the text-aligned priced-table route does not return this table. PDflow falls back to the existing routes and surfaces a warning instead.

Limit: this route has been tuned and validated on two real priced documents so far. That is evidence of feasibility, not proof of generality. It currently targets quotations and invoices with Quantity, Unit Price, and Total/Amount-style headers.

Online Beta workflow

What happens when you run a PDF online.

The Online Beta is automatic: your browser uploads one PDF to the hosted worker, PDflow selects a supported route, runs its checks, and returns READY, REVIEW, or NO OUTPUT.

Step 01

You upload one PDF to the Online Beta.

The hosted worker receives the PDF and queues it if another conversion is already running.
